# UniShare — ตลาดส่งต่อของรุ่นพี่สู่รุ่นน้อง (สาขา IT · PIM)

เว็บสำหรับนักศึกษาสาขาเทคโนโลยีสารสนเทศ PIM ให้รุ่นพี่ส่งต่อของที่ไม่ใช้แล้ว (แจกฟรีหรือขายราคานักศึกษา)
พร้อมคลังชีทสรุปแยกรายวิชา กระทู้ถาม-ตอบแนบไฟล์ได้ รีวิวสื่อการเรียน คลิปติว และแผงควบคุมแอดมิน

## โครงสร้าง
- `index.html` — เว็บทั้งหมดในไฟล์เดียว (Vanilla JS + CSS)
- ฐานข้อมูล / สมัครสมาชิก / ไฟล์ — **Supabase** (Postgres + Auth + Storage)
  - Row Level Security ทุกตาราง: แก้/ลบได้เฉพาะเจ้าของหรือแอดมิน
  - สมัครได้เฉพาะอีเมล `@pim.ac.th` และต้องกดยืนยันอีเมลก่อนใช้งาน
  - ไฟล์อัปโหลด (ชีท, รูปสินค้า, ไฟล์แนบ, คลิป) เก็บใน bucket `uploads` สูงสุด 10MB
- โฮสต์ — Render Static Site (`render.yaml`)

ถ้าลบค่า `UNISHARE_SUPABASE_URL` / `UNISHARE_SUPABASE_KEY` ใน `index.html` เว็บจะกลับไปเป็น **โหมดสาธิต** (เก็บข้อมูลในเบราว์เซอร์)

## ตารางในฐานข้อมูล
profiles · subjects · notes · items · item_contacts · threads · thread_replies · reviews · review_votes · videos ·
notifications · reports · announcements · audit_logs
